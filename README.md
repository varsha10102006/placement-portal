# 🎓 Placement Portal

A React-based web application designed to help students prepare for placement opportunities.

## 🚀 Features

- 🔐 User Login
- 📝 User Registration
- 📊 Student Dashboard
- 📚 Aptitude Practice
- 💼 Job Application Tracker
- 📄 Resume Skill Analyzer
- 👁️ Show/Hide Password
- 🔄 Easy navigation between sections

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- Git
- GitHub
